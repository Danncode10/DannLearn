# Subjects

Each folder in this directory represents one subject.

Use this shape:

```text
Subjects/
  <SubjectName>/
    resources/
      raw/
      processed/
    reviewers/
    quizzes/
    flashcards/
    notes/
    index.md
```

`Subjects/` is local content by default. Do not upstream private resources,
personal notes, or generated study material unless the user explicitly asks.
