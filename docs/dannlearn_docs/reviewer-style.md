# Reviewer Style

Reviewers should help a learner understand and recall material, not merely store
a long summary.

The canonical reviewer artifact is Markdown:

```text
Subjects/<Subject>/reviewers/<topic-slug>/reviewer.v001.md
```

The reviewer itself is the Markdown artifact.

## Preferred Shape

- Start with scope and sources.
- Organize topics in learning order.
- Explain terms plainly.
- Include examples, contrasts, and quick checks.
- Preserve learner quote notes when a reviewer is created with `-quote`.
- Distinguish course-grounded claims from clearly labeled learner-supporting
  context such as analogies and familiar examples.
- Add a small set of visual search suggestions when visuals would materially
  improve understanding.
- Mark gaps where resources are incomplete.

## Avoid

- Unsupported facts.
- Overly broad flashcard-like bullet dumps.
- Repeating the same point in several sections.
- Hiding uncertainty.
- Passive summaries without recall prompts.
- Repetitive concept-by-concept sections when a topic-based explanation or
  comparison would teach more effectively.
- Unlabeled outside context presented as though it came from the course source.
